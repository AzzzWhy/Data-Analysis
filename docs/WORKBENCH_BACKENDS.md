# 8877 工作台：本机与 SSH 远程计算

只打开本机的 `http://127.0.0.1:8877/`。工作台页面、登录页、CSS、JS 始终由本机提供；文件列表、分析任务、进度事件和报告由当前选中的计算后端提供。切换会刷新页面，不会把旧结果误认成新机器的结果。远程断开时不会偷偷改在本机计算，可以在“计算连接”窗口切回本机。远端要求重新登录时，登录页左上角也保留该入口。

## 启动本机工作台

在项目根目录运行：

```powershell
python -m pip install -r requirements-gui.txt
python agent/frontend_gateway.py --port 8877
```

如旧的 `agent/gui.py --port 8877` 仍在运行，先正常停止旧服务；两个程序不能同时占用 8877。网关默认仅监听本机回环地址。登录仍使用本机原有的工作台密码。

8877 网关没有已设置密码时，会显示“设置访问密码”，不直接放行到工作台。这个密码保护本机工作台入口，既不是 SSH 登录密码，也不是模型服务密钥。

## 退出登录与恢复初始状态

- **退出登录**：结束登录会话，保留连接设置、数据与报告。只想返回登录页时，不需要恢复初始状态。
- **恢复初始状态**：需要再次确认，会重置本机工作台的会话、缓存、连接配置和浏览器设置的访问密码；不会删除数据文件或已生成报告。成功后进入“设置新访问密码”页，因为旧密码已被删除，不能再用旧密码登录。新密码请由使用者自行设置。
- 重置后的首次设置要求会持久保存；重启也不会恢复成免登录。若服务用启动参数 `--token` 指定了访问密码，则该启动密码保留，重置后回到登录页。
- **远程模式禁止通过此按钮重置服务器**。先在“计算连接”中选择“使用本机”，再决定是否重置本机；界面会显示这一限制，不以一个无说明的灰按钮代替解释。不同浏览器的本机/远程选择分别保存在各自 Cookie 中，可能因此呈现不同状态。
- 重置失败或网络中断会在按钮旁提示，不自动重发重置请求。若无法确认结果，先刷新核对，不要连续点击重置。

来源校验错误与 SSH 密码、模型密钥无关：它表示浏览器请求的来源信息没有通过网关检查。某些嵌入浏览器会在 Origin 中省略本机端口；网关仅对此特定回环格式兼容，仍要求正确 Host、本机登录和当前会话 CSRF 令牌。显式异端口和外站来源继续拒绝。请始终从本机的 8877 页面操作，不把设置请求复制到其他网站执行。

## 连接 GB10 或其他 SSH 主机

远端先运行与本机工作台兼容的 `agent/gui.py`，只监听远端 `127.0.0.1`，例如端口 8765。随后在 8877 页头点击“计算连接”，填写：

- SSH 地址：`ssh://用户名@主机:SSH端口`，例如 `ssh://Developer@your-host:6060`。
- 也可粘贴常用命令 `ssh -p 6060 Developer@your-host`。这里只解析连接信息，不执行命令；不支持附带远程命令、转发参数或 `ProxyCommand`。
- 后端端口：远端 `agent/gui.py` 监听的端口，例如 `8765`。

选择认证方式再点击“连接 SSH”：

- **密码**：在窗口内输入 SSH 登录密码。不需要在另外的终端输入；密码不会保存为下次默认值。
- **自动密钥 / SSH agent**：使用本机 SSH agent 或默认私钥；已配置免密登录时无需填写密码。
- **指定私钥**：填写本机私钥文件路径，需要时输入私钥口令。不要把私钥内容或密码粘贴到地址栏。

托管 SSH 使用可选的 Paramiko 依赖，只需安装在运行 8877 网关的电脑上，远端 GPU 后端无需安装。它读取本机 `~/.ssh/known_hosts`：已知且匹配的主机可继续认证；未知主机会先展示算法和 SHA256 指纹，必须通过可信渠道核对后明确确认，才会发送用户认证信息。确认只对本次连接有效，不写入 known_hosts；已知指纹冲突会拒绝连接，不提供绕过按钮。高级 OpenSSH 配置（如 ProxyJump）不由该表单自动读取，可使用下文的手动隧道方式。

界面分别显示 **SSH 认证状态** 和 **远端后端状态**。SSH 已连接不等于后端已经启动：例如后端端口填错、远端 API 不兼容或需要登录，都会单独提示。SSH 端口（例 `6060`）用于登录机器，后端端口（例 `8765`）用于转发到那台机器的服务，不能混用。

新连接就绪前不会替换当前计算连接。就绪后手动点击“使用远程”切换；如果远端需要工作台登录，则先进入远端登录页。再次打开窗口可“使用本机”“使用远程”或“断开 SSH”。外部终端建立的旧隧道会标为“外部隧道”，不表示刚输入的新地址已经成功，也不能由工作台代为关闭。

SSH 密码和私钥口令只经已登录的本机网关用于本次认证，不写入配置、浏览器存储、命令行或日志；表单在提交/关闭时清空敏感输入，服务端在认证结束后清理自身持有的凭据引用（不承诺操作系统内存的物理擦除）。地址只保留在当前网关进程内。连接操作要求本机登录与当前会话的 CSRF 校验，允许同端口回环地址及携带有效校验值的嵌入页面，不开放任意跨站请求。

远端 API 模型设置与 SSH 连接不同：SSH 决定**在哪台机器分析**，模型 API 地址、密钥和模型决定**那台机器调用哪个模型**。切到远端后，工作台“连接设置”作用于远端的模型配置。

模型设置中，不勾选“保存密钥”也可以立即对话：密钥只在当前后端进程内存中使用，不返回浏览器、不写入配置文件。刷新页面仍可使用；后端重启后需重新输入。勾选后才会保存在**当前计算后端**的明文配置文件中。取消勾选会移除已保存的密钥，但当前进程可继续使用；更换 API 地址会清除旧地址的密钥与模型，避免跨服务商发送凭据。后端正在分析时不能更改模型设置。

若使用后端机器上的无鉴权本地模型：API 地址填该后端所能访问的回环 OpenAI 兼容地址（例如 `http://127.0.0.1:11434/v1`），密钥填占位符 `local`，点击读取模型列表后选择实际已部署的模型。远程模式里的 `127.0.0.1` 指远端后端机器，不是浏览器所在电脑。

这里的 **API 是模型服务接口，不等于购买第三方云 API**。部署在 GB10 的模型通常仍由 Ollama、vLLM 等服务提供 HTTP 接口，Agent 通过接口调用它，不是在浏览器中直接加载模型权重。Ollama 的 OpenAI 兼容地址通常是 `http://127.0.0.1:11434/v1`，vLLM 按实际监听端口填写，例如 `http://127.0.0.1:8000/v1`。无鉴权服务里的 `local` 只是客户端兼容占位值；如果部署者开启了服务鉴权，应填该服务真正的访问密钥。参见 [Ollama 官方兼容说明](https://docs.ollama.com/api/openai-compatibility)。

当选择远程计算后端时，数据分析和模型调用均从那台后端发出。因此 GB10 上的模型只需允许 GB10 本机访问，不必另把模型端口开放到公网或转发到浏览器。模型需提供兼容的聊天与工具调用能力；“能读取模型列表”不代表所有模型都能完整运行 Agent。

## 结果与故障恢复

驻留会话的摘要、字段概况和异常检测结果与普通分析一样显示实际数据表；详情中仍保留原始工具结果。登录页不展示未经测量的行数、加速比或耗时，运行后的数字以工具结果为准。

关闭 SSH 连接弹窗会清空密码/口令，但不会擅自切换页面或中断已建立的隧道；需要取消认证或关闭托管隧道时使用“断开 SSH”。认证失败、超时、主机指纹拒绝、后端不可达分别提示，不会反复自动尝试密码。连接断开后不会自动转到本机或旧隧道。刷新工作台后无需重输已建立连接的密码；重启网关后需重新连接。

远程计算要求远端 Python 环境具备实际分析依赖。连接成功只说明 API 可达，不代表每种数据格式或 GPU 环境已安装；例如 Parquet 需要 `pyarrow` 或 `fastparquet`，GPU 路线需要 cuDF。若 SSH 隧道中断，页面会明确提示远端不可达，不会自动把计算转到本机。

`--remote-url http://127.0.0.1:端口` 仍可兼容已经手动建立的本机 SSH 转发，但不再是正常使用的必需步骤。网关只接受回环 HTTP 地址，不接受公网 HTTP 代理目标；旧的 8878 不再作为第二个前端。
