# 8877 工作台：本机与 SSH 远程计算

只打开本机的 `http://127.0.0.1:8877/`。工作台页面、CSS、JS 始终由本机提供；文件列表、分析任务、进度事件和报告由当前选中的计算后端提供。切换会刷新页面，不会把旧结果误认成新机器的结果。远程断开时不会偷偷改在本机计算，可以在“计算连接”窗口切回本机。

## 启动本机工作台

在项目根目录运行：

```powershell
python agent/frontend_gateway.py --port 8877
```

如旧的 `agent/gui.py --port 8877` 仍在运行，先正常停止旧服务；两个程序不能同时占用 8877。网关默认仅监听本机回环地址。登录仍使用本机原有的工作台密码。

## 连接 GB10 或其他 SSH 主机

远端先运行与本机工作台兼容的 `agent/gui.py`，只监听远端 `127.0.0.1`，例如端口 8765。随后在 8877 页头点击“计算连接”，填写：

- SSH 地址：`ssh://用户名@主机:SSH端口`，例如 `ssh://Developer@your-host:6060`。
- 后端端口：远端 `agent/gui.py` 监听的端口，例如 `8765`。

点击“连接 SSH”。Windows 上会弹出系统 OpenSSH 终端，首次连接时按终端提示核对主机指纹，并在终端输入 SSH 密码；若已经配置 SSH 密钥，也可直接验证。密码**不要**放进 SSH URL，工作台不接收、不保存 SSH 密码。连通且远端接口版本兼容后，页面自动切到远程。再次打开窗口可“使用本机”“使用远程”或“断开 SSH”。远端地址只保留在当前运行的本机网关内，不写入 Git 仓库或浏览器存储。

远端 API 模型设置与 SSH 连接不同：SSH 决定**在哪台机器分析**，模型 API 地址、密钥和模型决定**那台机器调用哪个模型**。切到远端后，工作台“连接设置”作用于远端的模型配置。

远程计算要求远端 Python 环境具备实际分析依赖。连接成功只说明 API 可达，不代表每种数据格式或 GPU 环境已安装；例如 Parquet 需要 `pyarrow` 或 `fastparquet`，GPU 路线需要 cuDF。若 SSH 隧道中断，页面会明确提示远端不可达，不会自动把计算转到本机。

`--remote-url http://127.0.0.1:端口` 仍可兼容已经手动建立的本机 SSH 转发，但不再是正常使用的必需步骤。网关只接受回环 HTTP 地址，不接受公网 HTTP 代理目标；旧的 8878 不再作为第二个前端。
